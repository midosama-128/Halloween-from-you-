배포 방법
1. index.html과 obake-kaigi.mp3 파일을 같은 폴더에 둡니다.
2. 두 파일을 함께 GitHub 저장소 또는 웹 호스팅에 업로드합니다.
3. index.html만 따로 올리면 음악이 재생되지 않습니다.

음악
- 파일: obake-kaigi.mp3
- 플레이어는 자동 재생하지 않습니다. 방문자가 재생 버튼을 눌러야 시작됩니다.
- 음량 설정은 같은 브라우저에 저장됩니다.

참고
현재 포스트잇은 브라우저 localStorage에 저장되는 프로토타입입니다.
다른 방문자와 메시지를 공유하려면 추후 데이터베이스 연결이 필요합니다.
